## 4. 标注规范

- 标注工具：LabelImg / X-AnyLabeling
- 标注格式：YOLO txt（`class x_center y_center width height`，均为归一化坐标）
- 标注原则：
  - 每个包裹目标单独画框，遮挡部分按可见范围标注
  - 堆叠包裹逐个标注，不合并成一个框
  - 模糊/严重遮挡（可见面积<30%）目标不标注

## 5. 数据增强策略

- 在线增强（YOLOv8 训练自带）：Mosaic、HSV 扰动、随机翻转、随机缩放
- 离线增强（`augment.py`，可选）：针对小尺寸包裹目标额外做远景缩放、运动模糊模拟

## 6. 数据质量控制

- 去重：基于文件哈希去重（`clean_dataset.py`）
- 剔除损坏图像
- 类别样本均衡检查：每类样本量建议不低于总量的 15%
